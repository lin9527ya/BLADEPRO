# SRC 平台规则模板（可直接粘贴到「SRC 工作台 → 平台项目」）

> 用法：工作台新建项目 → 把对应 JSON 贴进「高级 / 规则」区域，或直接
> `POST /api/src/programs`。
> **纪律**：平台规则会改版。模板里的条目抄自 `src-dig/知识库/<平台>src-rules.md` 的建档快照，
> 建档日期见每节标题；提交前**必须**对照当日官方规则页复核一遍。模板只做起点，不做依据。
> 标注 `（F2）` 的字段在当前版本会被忽略（JSON 解码忽略未知键），随 F2 生效。

## 字段速查

| 字段 | 含义 | 生效 |
|---|---|---|
| `check_tier` | `full`（默认）/ `platform`（手工等价物）/ `off` | F2 |
| `check_thresholds` | 覆盖内建门槛，键为指标名（`paths` / `manual_paths` / `retested` / `methods` / `state_methods` / `variants` / `contrasts` / `external_exits` / `dns_resolvers`） | F2 |
| `no_automation` | 编译"禁扫描器/禁全端口/禁洪水"命令级规则 | F2 |
| `max_records_read` | 越权读取上限（合规检查提示用） | F2 |
| `require_screenshots` | 收尾项 `screenshots` 不再允许 `na` | F2 |
| `strict_layout` | 导出严格 8 块（备注退出正文） | F3 |
| `egress_ip` / `test_accounts` | 提交块字段 | F3 |
| `redlines` | 平台原始红线，逐条进 planner/worker 提示词 | F2 |
| `forbidden_techniques` / `forbidden_writes` | 复用 `policy` 词表 ID | 已生效 |
| `max_intents_total` / `max_intents_per_round` / `max_open_intents` | 额度（取更小值） | 已生效 |
| `command_rules` | `[{label, pattern, regex}]`，追加进命令门 | 已生效 |
| `rate_limit` / `time_window` | 限速与作业时间窗 | 已生效 |
