# src-authz —— 越权判定与 ID 获取（单账号作业）

> 模式真身 §8.5 的完整展开。任何 ID / 归属类测试前先加载；学到的新手法回填本文件（标 `invented`）。
> 被拦时的绕过打法在 skill `src-bypass`。

## 0. 原则

- 越权核心：**证明你碰到了不属于你的对象**，不是开两个账号做对照。
- **单账号是默认作业方式**——把力气花在"弄到别人的 ID / 参数"上，不是"再养一个号"。
- 拿到 ID 的三条路**同等正当**：**拿**（目标自己泄露的）、**猜**（按格式规律构造）、**遍历**（有限空间枚举）。
- **每个接口都伴随一问：这个接口会吐出别人的 ID 吗？**

## 1. 有效越权三要素

| 要素 | 要求 |
|---|---|
| **对象归属他人** | 能说明这个 ID / 租户 / 手机号对应的资源不属于当前身份（回包 owner/tenant/手机号与当前账号不一致） |
| **ID 来源可信** | 说清 ID 怎么来的（泄露 / 猜解 / 遍历 / 参数替换都行）。**纯数字可遍历不用解释来源** |
| **影响落到终点** | 读到他人数据 ≥1 条非测试数据 / 未授权写删成功 / 能接管——只回 200 或空列表不算 |

## 2. ID / 参数获取策略（11 类 + C 猜解 + D 遍历）

**先判型（可遍历性）**：自建 3–5 个对象做序列差分 → 自增（L1 直接枚举）/ 雪花·时间戳（L2 可推理）/ 短码（L3 受限字典）/ 随机·加密（L4 不可枚举 → 走下面 1–11 类"从其他功能接口获取"）。
辅助：ID base64/hex 解码看明文；哈希类查字典（`md5(uid)` 类）；对比前缀与位数；试双形态 ID（业务 ID ↔ 数据库 ID）。

| # | 策略 | 具体动作 |
|---|---|---|
| 1 | **自己的列表/详情接口回包** | 列表里常混他人条目（共享空间/公开目录/推荐位/评论/协作成员）；先翻完自己的列表，捡出非自己创建的 ID |
| 2 | **导出 / 批量 / 报表接口** | `/export`、`/download`、`/report`、批量查询常按 tenant/org 返回，越权概率远高于单条详情 |
| 3 | **创建/邀请/协作者的返回值** | 建协作/分享/邀请，回包常带被邀请人或成员的 ID、uid、手机号 |
| 4 | **分享链 / 公开页 / 免登录页** | 分享页、H5、预览链常带明文 ID 或可解密的密文 ID |
| 5 | **搜索 / 联想 / 建议接口** | 搜他人昵称/手机号/工号，回包带 ID |
| 6 | **ID 形态变换** | 明文↔密文（base64/hex/自研加密）；自增/雪花做**邻位取样**；手机号/工号/email 直接当 ID |
| 7 | **参数直接就是身份** | `userId`/`tenantId`/`orgId`/`createBy`/`phone` 在 body 或 query → 换成他人值重放（Mass Assignment） |
| 8 | **侧信道 / 旁站 / 旧接口** | 旧版 API、内部域名、H5、小程序、App 抓包里同一资源的另一种鉴权（常缺校验） |
| 9 | **多站关联** | SSO 域下另一站点的同 ID 直接复用（记 `site_link`） |
| 10 | **附件 / 图片 / 文件 URL 与 CDN 路径** | 头像、附件下载、图片服务 URL 路径常含 uid/用户目录/可推导命名；上传回包文件名、文件元数据、EXIF；把 URL 路径当 ID 源 |
| 11 | **ID 映射推导链** | 低敏感接口泄露 uid/工号/手机号 → 去高敏感接口换资源 ID；两接口字段互推（评论接口给 uid+评论 id、订单接口给订单 id、消息回执给双方 ID）；Swagger/文档示例值 |
| **C** | **ID 猜测** | 自增数字、工号规则、日期+序号、短码/短链、前缀+数字、时间戳、手机号段。先构造 3–5 个试探格式对不对，再定向扩 |
| **D** | **ID 遍历（枚举）** | 纯数字 / 短码 / 有限空间直接推进：连续整数、步长跳、区间抽样、短码字典。**遍历是正当手法**，不是"碰运气" |

## 3. 遍历纪律（既不放过漏洞，也不打挂生产）

- **总量硬上限 20000 条**：单次遍历任务**不超过 20000 个请求**，到顶即停。估算空间 > 20000 时只做定向构造 + 区间抽样，并在台账写明"未全量遍历"。
- **阶梯推进**：采样 200 探命中率 → 批量 2000 校准速率 → 全量至 20000（硬上限）。命中率高再扩，别一上来扫满。
- **命中即停手取证**：拿到 1–2 条非测试数据就够立论，**立刻停止遍历**，转入取证与升链。上限是"允许的最大值"，不是"要打满的目标"。
- **速率与风控**：单端点 ≤2 req/s；触发 429/风控/封禁 → 停 5 分钟、换出口（走 `src-bypass`），**不硬刚**。
- **禁脱库**：不许"遍历全量导出"当成果；PII 上限 10–20 条。
- **有限空间优先**：短码、4–6 位数字、小范围自增（≤1000）性价比最高；大空间（手机号、长雪花 ID）只做定向构造，不做盲扫。
- **有副作用的口不遍历**：发短信、发邮件、扣费/下单、触发下游任务、产生通知类副作用的口，一个都不遍历，只做单点验证。
- **必须证明归属**：遍历/猜到的 ID 要能说明该对象**不属于当前身份**，只"撞到一个陌生 ID"不算。

## 4. 同 ID 换路径复用

拿到一个他人 ID 后，把**所有接受该 ID 的接口**都重放一遍（详情/编辑/删除/导出/统计/消息/日志）——同一对象在不同接口上的鉴权强度常常不一致，这是最省力的扩面方式。

## 5. 越权最小完成量（"改个 id 看一眼 200"不算测过）

| 维度 | 最少做到 |
|---|---|
| 同一对象换接口 | 详情 / 编辑 / 删除 / 导出 / 统计 / 消息日志——逐接口重放，记录各自鉴权结果 |
| 同一接口换 ID 形态 | ≥3 类：明文数字、密文/编码 ID、身份参数（userId/tenantId/phone/工号）、邻位/区间抽样 |
| 同一参数换位置 | query ↔ body ↔ header ↔ Cookie；GET ↔ POST ↔ PUT/PATCH |
| 拿到数据才算数 | 回包 owner/tenant/手机号与当前账号不一致 + ≥1 条非测试数据；只回 200/空列表 = 未完成 |
| 服务端兜底 | 客户端类必须先打服务端（errcode / 真实状态变更），否则停在 `observed` |

四个维度都过完，这条候选才允许写"测过/无洞"。少一维就写清缺哪一维、为什么（不留空）。

## 6. 红线（报前逐条对）

- **不许只给一个请求包就声称越权**——必须说清这个 ID 怎么来的、为什么它不是你的。
- **最小伤害序**：先读（证明能读到他人数据）→ 再添加（能否挂到别人名下）→ 再删自己刚加的那条；只能动现成对象时只改自己能改回的字段，打一次立即改回。
- **禁批量改删、禁真资损、禁脱库**；PII 拉取限 10–20 条，够证明即止。
- 服务端兜底没实测 → 标 `observed`，不得升 `impact_proven`。
- **零脱敏**：ID、凭证、证据、报告全部原值留档（不脱敏；不公开披露）。

## 7. 报告三段式（单账号）

```
【对象归属证明】
  ID 来源：<接口回包 / 猜解规则 / 遍历区间 / 参数替换 / 泄露；纯数字可遍历不用解释来源>
  归属证据：<该对象的 owner/tenant/手机号 与当前账号不一致的具体字段与值>
【越权验证】
  <单账号 + 该 ID 重放的请求/响应，标 payload_source>
【影响终点】
  <读到了什么他人数据 / 写删了什么 / 是否可接管；服务端兜底实测结论>
```
