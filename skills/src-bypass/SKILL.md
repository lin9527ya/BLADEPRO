# src-bypass —— 被拦 = 换打法（硬）

> WAF / 403 / 429 / 风控 / 证书钉死 / 加固 / 反调试，都只是"这一招不行"的信号。
> 任一口被拦，先把这个口的五层走完再谈其它；**拦截本身还是线索**（429=有速率语义、403 差异=有鉴权分支、加固=有值得保护的东西）。

## 1. 绕过分层

- **WAF/拦截**：编码混淆（双重 URL/Unicode/Hex/注释拆分/空字节）→ 方法切换（GET↔POST↔PUT/PATCH）→ Content-Type 切换（form/json/multipart/xml）→ 路径变体（大小写/尾斜杠/分号穿越/后缀/双写）→ 参数移位（query↔body↔header↔Cookie）→ 换入口（H5/App/旧版 API/内部域名）。
- **403/隐藏接口**：路径 fuzz（admin 变体、`/v1/`↔`/v2/`、后缀）→ JS/注释里的死端点提取 → 动词探测 → App/H5 抓包找 Web 上没有的接口。
- **越权被拦**：身份参数移位重放 → 对象 ID 形态变换（int↔uuid↔加密串↔手机号/工号）→ 换批量/导出/统计类接口重放同一对象 → 低权 token 打高权接口。
  越权主路径是"拿到别人的 ID/参数"，不是开两个账号做对照（见 skill `src-authz`）：**拿 / 猜 / 遍历**，三条路都正当。
- **逻辑绕过**：状态机跳步、金额边界（负数/0/超小数/溢出）、并发竞态（券/余额/签到）、步骤断链。
- **隐藏面**：参数 fuzz（`debug`/`test`/`isAdmin`/`internal`/`role`，字典优先用目标语料自生成）→ 旧版接口未下线 → 前端配置泄露的内部入口。

**纪律**：主要类别都试过仍被拦，才允许降速后回来补测；每次绕过尝试记入台账（试了什么、结果如何）；**禁止"有防护就跳过测试点"**。碰认证墙走破局树，不搁置。

## 2. 认证墙破局树（1→6 逐级，全不通才判死路）

| 级 | 路径 |
|---|---|
| 1 | Web 自助注册（顺手试 `roleType`/`tenantId`/`isAdmin` 拔权） |
| 2 | 注册流程逆向（captcha / SMS / sign 参数自实现） |
| 3 | 签名已破缺 token：注册最低权号补真 token，伪造签名 + 真 token 组合重放 |
| 4 | APK/小程序脱壳取运行时密钥/固定 token（真机按技能） |
| 5 | SSO 壳破局（壳后账密口 + JS 里第二套登录端点 + `/auth/*` fuzz）+ 旁站凭证复用 |
| 6 | 向 SRC 申请测试账号（硬目标唯一合法突破口，别不试就放弃） |

拿到会话后**回填重打全部 ⚠️**（未认证态穷尽只是热身，认证态才是 IDOR 主产区）。

> 完整版（含第 7 级"判死路"与决策要点）在 `（外部知识库未随包提供）\src\opencode\src-mode\kb\auth-ceiling.md`；改一处必须同步另一处。

## 3. 客户端侧被拦（加固 / 反调试 / 证书钉死 / 反模拟器）

- 证书钉死、抓不到包、反 Frida → 加载 `android-stealth-hook` 技能（无痕 Hook / 过检测），按技能文档执行。
- 加固壳（梆梆/爱加密/乐固/jadx 只见壳）→ 加载 `android-dex-dump` 技能（脱壳）。
- 反模拟器检测 → 记录 `observed`，转真机（Pixel 6 Pro / magic root，见模式 §6.1 权威性分级）。
- **结论口径**：真机（Pixel 6 Pro / magic root）结论可升 `impact_proven`；只有模拟器限定 `observed`。反检测 / 银行级加固首选 Pixel 6 Pro；结论记设备标识。
