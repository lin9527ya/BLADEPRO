## §0 ENScan MCP（企业面主引擎 · 由 BLADEPRO MCP 提供 `mcp__ENScan__*`）

> **开工先解锁**：ENScan 由 BLADEPRO 的 MCP 提供（设置 → MCP，name=`ENScan`，`http://127.0.0.1:18081/mcp`）。本技能 frontmatter 声明了 `mcps: ENScan`，**先调用 `Skill(src-recon)` 解锁** `mcp__ENScan__*`，再来查企业。
> **工具不在** = MCP 没连通，不是技能坏了。确认 BLADEPRO 启动环境有 `BLADEPRO_MCP_ALLOW_LOCAL=1`、18081 端口在听、设置页里 ENScan 是启用状态；不要自行起服务、也不要伪造结果。
> **超时口径**：MCP 客户端单次调用 120s 超时，大公司**禁止**同步 `collect_company_info`，一律 `collect_company_info_async` + `task_status` 轮询（间隔 ≥20s），job_id 记进清单备注。

**企业信息批量收集首选**——关键词一次拿全 12 类：icp 备案🔥 / invest 对外投资 / holds 控股 / branch 分支机构 / partner 股东 / wechat 公众号 / wx_app 小程序🔥 / app / weibo / job 招聘 / copyright 软著🔥 / supplier 供应商。爱企查/小蓝本 playwright 手采降为**补充与交叉验证**（enscan 某类缺失或要详情页字段时）。

**标准调用链：**

```
1. mcp__ENScan__search_company(type="rb", name="<品牌名/公司名>")   → 候选公司 + PID
2. 小目标: mcp__ENScan__get_page_info(type="rb", name="<PID>", filed="icp", page="1")  → 分类分页查
   大目标: mcp__ENScan__collect_company_info_async(name="<公司名>", filed="icp,invest,wx_app,app,job,copyright",
           type="rb", invest=100, depth=2, branch=true) → 返回 job_id
3. mcp__ENScan__task_status(job_id="...")                          → 轮询(done 拿全量数据)
```

**口径对齐：** invest=100 只出 100% 全资（**天然过股权闸 §3.2.0**）；depth 逐层递归=§2 递归规则代码化；icp 结果直接回灌 §3 备案号递归线（域名+备案号一锅端）；copyright 软著名→系统名入口（§4 火线）；wx_app/wechat/app→07 §1/§2；job→04 §3 JD 反哺。
**空结果先查 `cookie_status`**——风鸟会话约 1 天过期（重取法见 ENV.md enscan 行）。当日查询有配额（limit:auth），大目标用 async 别连环同步刷。**渠道故障切换**：某渠道某维度返回「处理异常」时换渠道重试（实测 2026-09：rb 的 wx_app/copyright/job/wechat 四维全坏 → tyc 渠道 copyright/wechat/job 可用，软著全扫即靠它）；**分页仅第 1 页稳定**（page≥2 常异常，20 条/主体是实际可得量）。

## §1 爱企查股权穿透（补充/交叉验证）

爱企查（`aiqicha.baidu.com`，百度系）SPA 渲染稳定、子公司展示全、联系方式不脱敏。**优先于小蓝本**。**enscan（§0）没覆盖的详情字段/瀑布式下钻交互场景用本节**。

**搜索词选择（核心经验，实战验证）：**

| 搜索词 | 效果 |
|--------|------|
| 品牌名（如「传胜」） | 一次出 10+ 家关联公司 |
| 公司全称 | 只有 1 条 |
| 高管/法人名（如「黄多多」） | 该法人担任法人/股东的**所有**公司 |
| 品牌矩阵（「黄记煌」「小肥羊」） | 全部品牌系公司 |

**操作（playwright MCP）：**

```
导航：https://aiqicha.baidu.com/s?q=<URL编码词>&t=0
读正文（browser_snapshot / evaluate 取 body text），逐条正则提取：
  公司名 / 状态（(开业|存续)）/ 法定代表人 / 注册资本 / 成立时间 / 电话 / 邮箱 / 地址
懒加载用 scroll 触发：for(i=0;i<8;i++){scrollBy(0,600);await sleep(350)}
```

**归属确认三判据：**

1. **法人统一**（同系公司法人常同一人）
2. **邮箱后缀统一**（`@yumchina.com` = 集团直管；子公司自有后缀 = 独立运营）
3. **注册资本 + 地址分布**（全国布局印证区域公司）

产出按 09 表格落 `资产/公司树`。

**playwright 会话模板（可复用调用序列）：**

```
1. mcp__playwright__browser_navigate  → https://aiqicha.baidu.com/s?q=<URL编码词>&t=0
2. 触发懒加载（browser_evaluate）:
   for(let i=0;i<8;i++){ window.scrollBy(0,600); await new Promise(r=>setTimeout(r,350)); }
3. 读正文（browser_evaluate）: document.body.innerText
4. 逐条正则提取（AI 解析，字段顺序注意多行）:
   公司名: /([^。]+?)有限公司[^。]*?(开业|存续)/
   法人: /法定代表人[：:]?(\S+)/    资本: /注册资本[：:]?([\d,]+万/
   时间: /成立时间[：:]?([\d-]+)/   电话: /电话[：:]?([\d-]+)\s/
   邮箱: /邮箱[：:]?([\w.@]+)/      地址: /地址[：:]?([^\n]+)/
5. 每查完一家立即落盘 JSON（资产/aiqicha_<公司名>.json）— 防浏览器会话断连丢数据
```

**降级：** 爱企查无登录态/被风控拦 → 改 WebSearch（`"<公司名>" 企查查 OR 爱企查 OR 天眼查 子公司`）拿文本摘要。

## §3 备案号递归反查（核心 🔥）

**原理：** 同一主体的备案号编号连续（-1、-2、-3...），每个数字可能对应一个子站。

```
Step 1: 找主备案号
  WebSearch("公司名 ICP 备案号") 或 FOFA icp="公司名"
  → 如 "青ICP备05001236号"
Step 2: 遍历子备案号（搜到无新结果为止）
  WebSearch("青ICP备05001236号-2 网站 OR 域名")
  WebSearch("青ICP备05001236号-3 网站 OR 域名") ...
Step 3: 备案信息里的 IP 反查 C 段
  WebSearch("<IP> 备案 OR 网站")
```

**实战案例（黄河水电）：** 青ICP备05001236号-2 → ljxsdz.com（李家峡）、-3 → 218.95.226.2、-4 → 218.95.226.112。

**工具路径：** `mcp__ENScan__get_page_info(filed="icp")`（**首选**：公司全量备案域名+备案号直接出，§0）；`https://beian.miit.gov.cn/`（官方，浏览器开）；`icp.chinaz.com`；FOFA `icp="备案号"`；Hunter ICP 主体信息直接展示（见 02）。

**FOFA ICP 正查实战：** `intel_search(expr='icp="<备案号前缀>"')` → 同号全后缀站点一锅端（实测 `icp="12025439"` 273 条，命中新增官方域 kefu.bytedance.com）。⚠️ **口径坑**：icp 匹配语义是「页面中含该备案号字符串」，不是备案库精确查询 → 结果混入 ①第三方白标站（zp.* 招聘壳）②合作方站 ③**仿冒站**（盗用备案号做 SEO，实测 ai-doubao.com.cn）——**全部须过归属闸**；仿冒命中本身记情报线索。

## §4 工商信息 → 资产线索（国内攻防核心）

数据源：天眼查 / 企查查 / 爱企查 / 国家企业信用信息公示系统（gsxt.gov.cn）。

| 维度 | 反哺什么 |
|------|---------|
| **对外投资/控股子公司** | >50% 可能内网互通/共用 VPN SSO，横向突破口 |
| **分支机构/关联企业** | 品牌/法人关联的新主体 |
| **软件著作权** | 登记名 = **系统名称** → `site:目标.com "系统名"` 或测绘 `q='title="系统名"'` 直查入口 🔥（批量取：`mcp__ENScan__get_page_info(filed="copyright")`，§0） |
| **商标** | 商标名 → 全网同名**小程序/APP/域名/公众号**反查（品牌矩阵；同名新主体入公司树；测绘 `q='title="商标名"'`） |
| **专利** | 产品线、新技术方向 |
| **曾用名/工商变更记录** | 旧公司名搜出的**旧域名/旧系统名**常还活着（改名前的系统没跟着改）→ 直接进测绘与搜索 |
| **年报/联系方式** | 邮箱格式（`fn.@xx.com`）、电话段（后续反查见 04） |

**软著→系统入口是高价值链路：** 软著登记名常就是内部系统名（「XX 集团供应链管理系统 V2.0」），拿系统名去测绘/搜索引擎直接定位登录页。

## §6 下级单位专项（子公司防护常比母公司弱）

对 §1/§2 找到的每个全资下级单位，**必查 5 项**：

```bash
# 1. 搜独立域名
WebSearch("<下级单位全称> 官网 OR 域名 OR 网站")
# 2. 搜登录/管理系统
WebSearch("<下级单位简称> 系统 OR 平台 OR 登录 OR 管理")
# 3. 搜招标暴露的系统名（转 05 深挖）
WebSearch("<下级单位全称> 招标 OR 系统改造 OR 信息化")
# 4. DNS 爆破（简称+常见后缀，用 tools/dns_brute.py --patterns）
# 5. 联系方式反查（邮箱/电话 → 新 IP 段，见 04）
```

**分公司专项（分支机构无独立法人，但常持独立备案号/域名）：** 工商「分支机构」列表逐个过 §3 备案反查——分公司备案的主体名带「分公司」后缀，直接搜母公司备案号会漏。

**下级单位资产优先级：**

| 类型 | 发现方式 | 优先级 |
|------|---------|--------|
| 有 ICP 备案的独立域名 | 备案反查 | ⭐⭐⭐ |
| 有登录页的管理系统 | 搜索/测绘 | ⭐⭐⭐ |
| 正在招标建设的系统 | 招标公告 | ⭐⭐⭐ |
| 疑似未确认域名 | DNS 爆破推测 | ⭐⭐ |
| 用总部域名的子路径 | host/xxx | ⭐⭐ |

**行业专有技术栈搜法**（发电→NC2000/H9000/SCADA；制造→DCS/MES/ERP；后勤→一卡通/门禁/OA）。

**港澳/海外子公司：** 股权树穿透到境外主体（BVI/香港/开曼壳除外）→ 转 `08-国际OSINT简表.md` §2（OpenCorporates/SEC EDGAR 企业注册 + 海外子公司常持独立海外域名）。

## §7 域名收集起点（公司名 → 域名）


## §8 递归闭环（强制）

对每个新发现的全资单位：记录四要素（全称/简称/地址/邮箱电话）→ 回 §7 搜域名 → 转 03 搜子域 → 转 05 搜招标 → 直到无新资产。**节奏上仍受 dig-scope 一种子闭环约束**：新单位域名入种子队列 pending，不是当场全搜。
