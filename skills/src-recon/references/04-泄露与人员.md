# 04 泄露与人员 — 代码/文档/社媒/人员反查

> **何时打开：** 找信息泄露（源码/密钥/文档/数据）；收集人员线索（邮箱/手机/QQ/社媒）；技术栈反推（招聘 JD）。
> **何时不打开：** 主线是资产测绘（02/03）；泄露搜了 1~2 轮无果且主线还有活面（及时止损，不是每轮全跑）。
> 来源：infogather Mode5（5.1-5.9）· information-gathering §2.3-2.5 · offensive-osint 国内部分（2026-09-07 蒸馏）。
> **凭据命中后：** 认钥闸与「可用凭证」判定认 `~/.claude/skills/src-dig/rules/src-value-hunting.md`；拿到 AK/SK 不当字符串抄进报告，当钥匙打能力例。

## §1 源码泄露（最高价值——直接拿逻辑/密钥/后台路径）

### 首选：Sourcegraph 流式 API（无需 token，主通道）

grep.app 429 限流 / GitHub code search 需 token / WebFetch 被域名校验拦——Sourcegraph `search/stream` 流式 API 免认证，curl 直连可用。

> ⚠️ 通道状态实测（2026-09-13）：本机直连 Sourcegraph 返回 **"Firewall Block" 拦截页**（grep.app 同步被 Vercel 挑战拦）——**先探一发**〔curl 一次看回的是不是 JSON 流〕，被拦即走降级：WebSearch `site:github.com "<域名>"` 裸搜（04 §1 GitHub 节），或挂 Clash 换路。别在死通道上连续重试。

```bash
# 单关键词
curl -s -m 60 "https://sourcegraph.com/search/stream?q=<关键词>&v=V3" \
  -H "Accept: text/event-stream" | grep -oE '"repository":"[^"]+"|"line":"[^"]{0,80}"' | head -50

# 批量：专有标识（域名/邮箱/系统名）逐词跑，结果落 资产/
```

**关键词特定性铁律（不可违背）：**

- ✅ 完整域名 `parkson.com.cn` / 邮箱 `shtax@parkson` / 系统名 `iparkson`
- ❌ 泛词 `parkson` → 229 仓库全是无关同名公司

### GitHub / Gitee / Coding.net / GitCode / GitLab

```
# GitHub（code search 需 token；无 token 用 WebSearch 裸搜）
WebSearch('site:github.com "<domain>" password OR secret OR token OR config')
WebSearch('site:github.com "<公司名>" 数据库 OR 配置 OR 内网 OR api')
WebSearch('org:<org> secret OR password OR apikey')

# Gitee（国内开发者常忽略安全）
WebSearch('site:gitee.com "<domain>" OR "<公司名>" password OR config')

# Coding.net（腾讯云效）/ GitCode（CSDN 系）——国内私有仓/迁移仓泄露高发, 搜法同 Gitee
WebSearch('site:coding.net "<公司名>" OR "<domain>"')
WebSearch('site:gitcode.com "<公司名>" OR "<domain>"')

# GitLab 自建实例：常见 8080/9090 端口 + /explore 公开项目
```

**GitHub dorks 备忘：**

```
"target.com" extension:env
"target.com" filename:*.config password
filename:.git-credentials target
path:.ssh/id_rsa target
filename:wp-config.php target
```

**历史提交深扫**（拿到仓库后）：`~/bin/trufflehog` / `~/bin/gitleaks` 已装（trufflehog git <repo-url> 全历史密钥扫描；gitleaks detect --source <目录>）；轻量兜底 `git log -p | grep -iE 'password|secret|key|token'`。

### 云存储代码包

```
WebSearch('<domain> OR <公司名> 代码包 OR source.zip OR backup filetype:zip OR filetype:tar')
```

**价值排序：** Sourcegraph 流式 API > GitHub 裸搜 > grep.app > searchcode。

## §2 文档泄露（国内特色）

### 网盘

> ⚠️ 网盘搜索引擎死亡率极高——用前先核验站存活, 每源记「核验日期」, 死了换下一家。

```
# 凌风云 lingfengyun.com / 云盘搜索 yunpz.net / 小马盘 / 超能搜（核验日期 2026-09-07; 浏览器操作或 WebSearch）
# 夸克/天翼/蓝奏/百度专用搜索站轮换试; 搜站死了 WebSearch('百度网盘搜索' 取当期存活站)
WebSearch('"<公司名>" 通讯录 OR 内部资料 OR 员工表 filetype:xls OR filetype:pdf')
关键词：公司名 + 拓扑图/台账/密码/账号/花名册/巡检表
```

### 文库 / 公开文档

```
# 百度文库/搜文库/360文库 + 道客巴巴 doc88.com / 豆丁 docin.com（两大主流补齐）
关键词：公司名 + 运维手册/实施方案/投标文件（常含拓扑、IP、账号）
# 语雀
WebFetch 或 playwright: https://www.yuque.com/search?q=<公司名>
  追加 +密码 / +内部 / +环境
```

### 招投标（转 05 专项）

中国政府采购网等：实施方案常含**网络拓扑、系统清单、IP 规划**。

## §3 社交媒体泄露（人员 = 社工核心入口）

```
# 微博（内部人员吐槽/截图）
WebSearch('site:weibo.com "<公司名>" OR "<domain>" 内部 OR 系统 OR 后台')

# 脉脉/领英（职位/部门/关系网 → 推断 IT 岗/高管）
WebSearch('site:maimai.cn "<公司名>"')
WebSearch('site:linkedin.com "<公司名>" OR "<domain>"')

# 招聘平台（JD 泄露技术栈/系统名 → 反哺测绘 🔥）
# 批量入口: mcp__ENScan__get_page_info(filed="job") → 公司全量在招职位+JD 一次出(01 §0), 本节搜索线作补充

WebSearch('site:zhipin.com OR site:lagou.com "<公司名>" 运维 OR 开发 OR 安全')
WebSearch('<公司名> 招聘 运维 OR 开发 JD 要求')
# 看准网 kanzhun.com（前员工点评/部门结构）; 牛客网 nowcoder.com（内推帖直接暴露员工真实邮箱格式, 比 linkedin site: 更直接）; V2EX（员工吐槽/内推, site:v2ex.com）

# 技术社区（内部系统截图）
WebSearch('site:csdn.net OR site:juejin.cn "<domain>" OR "<公司名>" 后台 OR 系统')

# 自媒体主体反查（企业号矩阵常挂联系人+系统公告）

```

**关键转化：** JD 里的系统名/中间件名 → 反哺 02 测绘（title=）与 05 招标反哺。

## §4 手机号 / QQ / IM 反查

```
# 手机号 → 机主/关联公司（企业信息平台公开页）
WebSearch('<手机号> 企业 OR 法人 OR 联系人')
WebSearch('<手机号> 企查查 OR 爱企查 OR 天眼查')
# 手机号 → 社交/简历
WebSearch('<手机号> 微信 OR 简历 OR 工程师')

# QQ 号 → 绑定公司/邮箱
WebSearch('<QQ号> 企业 OR 邮箱 OR 绑定')
# 企业QQ/客服号 → 背后公司
WebSearch('<QQ号> <公司名> 客服 OR 技术')
# IM 群泄露
WebSearch('<公司名> QQ群 OR 微信群 泄露 OR 截图')
```

**来源：** 招标公告联系人、爱企查详情页、01 §1 采集的 emails/电话。拿到一个立即反查，再反哺。

## §5 邮箱收集与反查

```
# 域名 → 邮箱格式
WebSearch('"@<domain>" site:linkedin.com')       # 员工邮箱格式（fn.@ / first_last@）
WebSearch('"<公司名>" 邮箱 OR 联系方式')           # 爱企查页 → 后缀即域名
# hunter.io 免费档按域名猜格式(first@/flast@, 08 §2)——国内目标同样可用

# 邮箱 → 反查其他域名/系统（WHOIS 注册人思路; whois 未装, 用 RDAP 等价）
curl -s "https://rdap.org/domain/<domain>" | grep -oE '"email"[^,]*|"name":"[^"]*"' | head
WebSearch('<邮箱前缀>@<domain> IP OR 服务器 OR 系统')
WebSearch('<邮箱前缀>@126.com OR @qq.com 招标 OR 项目')
```

## §6 人员溯源完整链路（收一个反查一个）

```
IP/域名 → WHOIS 注册人/邮箱/电话
              ├─ 邮箱反查 → 其他域名/系统（01 §1 三判据）
              ├─ 手机号反查 → 名下公司 → 新资产
              ├─ QQ/微信反查 → 关联人员 → 社交关系
              └─ 社交媒体 → 职位/部门 → IT 岗/高管 →（社工入口，仅在授权范围内）
              ↓
          招聘 JD → 技术栈/系统名 → 反哺 02 测绘 / 05 招标
```

**人员收集优先级：邮箱 > 手机号 > QQ/微信 > 社交账号。**

## §7 密码/凭据线索（认钥纪律）

- 命中的账密/密钥 **当钥匙**：先验证是否真有效（登录/签名一次，不影响线上），不是抄字符串进报告
- 中间件默认口令 → 查 `~/.claude/skills/src-dig/知识库/cn-fingerprint-creds.md`（国产组件指纹+默认口令表）
- 登录表单弱口令字典**不当必做**（`dig-scope` §4.1.1）；JS/页面里的演示号/测试租户是合法钥匙
- 泄露库（HIBP/Dehashed 等）为国际源 → 见 08 §2

## §8 持续监控源（一轮搜不到 ≠ 永远没有）

| 源 | 用法 | 场景 |
|----|------|------|
| tgstat.com | Telegram 频道/消息搜索 | 内部群截图/数据贩卖频道（关键词=公司名/域名） |
| 猎鹰情报 lieying / SOUIZ | TG 深度搜索聚合 | tgstat 搜不到时换路（⚠️ 小站死亡率高, 用前核验存活） |
| 凌风云 lingfengyun.com | 网盘搜索（API 页面; 核验 2026-09-07） | 通讯录/台账类文档持续出现 |
| GitHub 仓库 Watch / gh trending | 目标 org 新仓库监控 | 新代码泄露第一时间 |
| Google Alerts / 镜像 | 公司名+关键词订阅 | 被动等新泄露 |

**节奏：** 监控源是长线，主线有活面时不占时间；一轮泄露搜索无果 → 记 pending 下轮再搜，不当空转磨。

## §9 节奏纪律

1. 泄露搜索是**围绕当前种子**的补充线，不是每轮全跑：主线有活面时先挖主线
2. 搜到的每条线索（域名/IP/邮箱/系统名）→ 立即入本站/本种子队列（09 §7 回灌）
3. WebSearch 有频次限制：分批，等结果回来再发下一批
4. 遇到蜜罐信号（IP 所有端口全开放）→ 标记跳过
