# 05 招标与供应链反哺 — 目标面瘦时的扩面路线

> **何时打开：** 目标 DMZ 资产测完发现不多（面瘦）要找新系统入口；知道目标用什么系统/供应商；要找同款系统的其他单位暴露实例。
> **何时不打开：** 当前种子还有大量活面没挖完（`dig-scope` §2.1 深挖优先，扩面不充进度）。
> 来源：infogather Mode7/10/17 · src-dig 知识库/supply-chain-recon §3（2026-09-07 蒸馏）。
> **核心思想：** 招标公告是信息宝藏——系统名/厂商/版本/地址/联系人一次全给。供应链思路转换：**不找目标，找目标用的供应商。**

## §2 系统名反搜（招标反哺流水线）

```bash
# 系统名 + 目标单位 → 登录页/IP
WebSearch('"正元智慧" OR "一卡通" "<单位名>" 登录 OR 系统 OR IP')
# 系统名 + 通用路径特征
WebSearch('"致远A8" /seeyon/index.jsp 登录')
# 厂商名 + 系统类型 → 同款其他单位实例
WebSearch('"浙江正元智慧" 一卡通 OR 食堂 登录')
# 版本号 → 默认口令/漏洞
WebSearch('"H9000 V4.0" 默认密码 OR 漏洞')
# IP 段反搜
WebSearch('218.95.226.2 OR 218.95.226.36 系统 OR 后台')
WebSearch('218.95.226.36 8080 OR 8443 OR 8000 OR 9090')
```

**实战流水线（黄河水电）：**

```
招标公告 → "浙江正元智慧一卡通系统 4.0.20.0531"
  → 搜 "正元智慧 一卡通 登录 黄河" → 发现 /CardManager/ 路径
  → 搜 "浙江正元智慧 默认密码" → 发现默认口令
  → 搜 "正元智慧 4.0.20.0531 漏洞" → 历史漏洞
```

## §4 供应商发散路线（供应链核心）

**原理：** 目标买的软件系统，同款也卖给了其他单位 → 其他单位的实例防护常更弱 → 找到默认口令/已知洞反哺目标。

```
① 拿供应商产品名：招标公告技术参数列 → 供应商官网「案例页」（客户列表+系统截图）
② 搜同款暴露实例：
   WebSearch('<供应商产品名> 登录 OR admin OR portal')
   WebSearch('<产品名> site:github.com')
   WebSearch('<产品名> 默认密码 OR 弱口令 OR 漏洞')
③ FOFA q='cert="<供应商域名>"' 透传（02 §1）→ 供应链域名/IP
④ 供应商 + 竞品单位 → 同类暴露实例
⑤ 供应商的合资/子公司 → 可能同时服务目标
```

**⚠️ 范围闸：** 其他单位的实例**不在授权范围**——供应链发散的价值是拿「同款系统的已知洞/默认口令」反哺**范围内**目标，不是去打别家。发现供应商合资公司 → 过股权闸（`dig-scope` §3.2.0）再决定入不入池。

**供应商信息源优先级：**

| 来源 | 提取什么 | 优先级 |
|------|---------|--------|
| 招标公告 | 系统名+供应商+版本 | ⭐⭐⭐ |
| 供应商官网案例页 | 客户列表+系统截图 | ⭐⭐⭐ |
| 百度百科/行业媒体 | 供应商背景+产品线 | ⭐⭐ |
| 招聘网站 | JD 技术栈 | ⭐ |
| 微信公众号 | 合作动态 | ⭐ |

## §5 双路并行六维度（供应链完整口径）

| 路 | 手段 | 能挖到 | 挖不到 |
|----|------|-------|-------|
| **A 路 FOFA** | cert/domain/ip 反查 | 域名/IP/证书/系统/端口 | 企业关系、供应商、人员 |
| **B 路 WebSearch** | 搜索/招标/企业库 | 供应商/招投标/人员/公众号/小程序 | 资产 IP、开放端口 |

**教训（百盛实战）：** 只走 A 路漏掉「富基旋风 SCM 供应商」等企业关系；只走 B 路拿不到 121 条资产明细。**必须双路并行。**

六维度清单：

```
① 域名资产     → FOFA cert/domain + crt.sh + HackerTarget
② Web 系统矩阵 → FOFA domain="主域" 翻页拉全（admin/scm/kibana/MinIO…）
③ 人员信息     → WebSearch + 爱企查联系方式反查（04）
④ 供应链供应商 → WebSearch + FOFA q='cert="供应商域名"'
⑤ 招投标线索   → WebSearch → 9 类字段提取（本篇 §1）
⑥ 高价值资产   → FOFA ip="关键IP" 全端口 → VPN/供应商门户/管理面板
```

## §6 高价值信号（供应链线上发现时标注）

- `xxx.scm/erp/oa` 类业务系统路径 + admin 入口
- kibana / MinIO / SoftEther VPN 等组件暴露
- **挂马信号**：目标某子域被博彩 SEO 劫持 = 弱管理 → 深挖线索
- 供应商同款系统的默认口令文档（CSDN/先知/看雪）

## §7 反哺闭环

每次从招标/供应链挖到新资产：新系统名 → 测绘 title= 直查入口；新 IP 段 → C 段/全端口（02）；新联系人 → 04 反查；新供应商域名 → 种子队列（过股权闸）。
