## §2 去重去废（认 `~/.claude/skills/src-dig/rules/dig-scope-workflow.md` §3.1，下文简称 dig-scope，此处速查 + 自动化）

**第一道闸（自动化·必跑）：`tools/dedupe.py` 资产去噪管道**

```bash
# 各源(CT/测绘/爆破/搜索)收集结果合并 → raw.txt → 一键去噪
python tools/dedupe.py --in raw.txt --out clean.txt --json report.json
```

| 去噪层 | 判定信号 | 处置 |
|--------|---------|------|
| 死域名 | DoH 无 A/CNAME（走 223.5.5.5 DoH——绕系统 DNS 污染/统一出口，结果稳定可信） | 剔除（dead） |
| 空壳跳转站 | 30x → 主站错误页（`error2.aspx from=shopdomain` / `jfe.html?err` / `/notfound` 类） | 剔除（removed，附原因） |
| 默认页壳 | 200 但标题 `Welcome to nginx/OpenResty` / `Insert title here` 类 | 剔除 |
| **CDN 域名** | CNAME 指向 CDN 厂商特征（qianxun/cloudflare/alibabadns/shifen/edgeone…）+ 3+ 域名共享同 CDN 接入点聚类 | **标注不删**（CDN 上有业务仍是资产；要源站见 03 §8） |
| **CDN IP** | A 记录落 Cloudflare 已知网段（本地判）+ ip-api ASN 含 CDN 关键字（远程判，每 IP 只查一次） | **标注不删** |
| 第三方 SaaS | CNAME → `*.service-now.com` 等托管 SaaS | 标注「非自建」（归属注意） |
| 存疑 | 根路径 404/405/410/502/503 | 单列 suspect（常有业务 path，进站前复查） |

**实测基线（jd.com 297 子域，2026-09-07）：** 噪音率 61%（181 空壳跳转+默认页），可用 100 + 存疑 12 + 死 4。同一 CDN 接入点（`ym.gslb.qianxun.com`）被 17 个子域共享。

**为什么 CDN 标注不删：** 401/403/登录墙 = 存活（`dig-scope` §1.0.1）；Cloudflare 后面可能有真业务（实测 moa.jd.com 走 CF 且有业务）。**「可用」= DNS 活 + HTTP 非壳**，CDN 与否不影响可用性，只影响「要不要溯源真实 IP」。

**人工级去废（工具判不了语义的）：**

| 该去 | 不该去 |
|------|--------|
| 同一 host:port 重复条 | 同 host 下不同 path/接口 |
| 假 TLD、业务键当域名 | `/api/a` 与 `/api/b` |
| CDN/静态/第三方库域 | 同 host 不同端口业务不同 |
| 内网 IP、无关站 | 同品牌不同业务 host |
| 停放页/纯静态无接口壳 | **401/403/登录墙（存活）** |

**整场任务全局去重（硬）：** 同一 URL 已在资产/covered → 跳过；同 host:port 已完成 → 跳过深挖；同 host **新 path/新端口** → **不跳过**；同皮镜像族已做代表 → 其余跳过全矩阵。多端来源（Web JS / APK）抽到同一 API → 合并，备注「双端确认」。

## §3 归属闸（认 dig-scope §3.2.0）

| 默认可入池 | 默认不入池 |
|------------|------------|
| 集团自身、100% 全资子/孙/曾孙/玄孙 | 参股、战略投资、合资非 100% |
| SRC 范围页明确列入的品牌/域名 | 投资组合公司自有域 |
| 已知全资品牌根域及业务子域 | 外包/第三方/公用壳 |

存疑才蜂鸟/证书/WHOIS/favicon hash 交叉（`dig-scope` §3.2.2；favicon 唯一性判据见 06 §3——非显性域名同 favicon = 同主体强判据）；**海外域是真实分支不当误报删**。

## §4 资产分级标注（与 dedupe.py 输出对应）

| 分级 | dedupe.py 归属 | 含义 | 去向 |
|------|---------------|------|------|
| 🟢 可用 | `keep`（clean.txt） | DoH 解析活 + HTTP 非壳（200/业务标题/登录墙/非噪音跳转） | 资产表，交 src-dig 进站 |
| 🟡 存疑 | `suspect` | 根路径 404/5xx（常有业务 path）；或归属待确认 | 待办列，进站前复查 |
| ⚫ dead | `dead` | DoH 无解析 | 记过不再碰（本任务） |
| 🔴 噪音壳 | `removed` | 空壳跳转/默认页 | 删除（原因在 JSON 报告可回溯） |
| CDN 标注 | keep 内带 tags | CDN 域名/IP——**可用但溯源另算** | 备注「CDN」，源站 IP 见 03 §8 |
| 🔥 暴露面 | keep 内备注 | actuator/swagger/.git/未授权组件 | 验证归 src-dig |

**重点优先（红队甜点区）：** 测试环境（uat/dev/staging）· 影子资产（老系统/废弃壳）· 有凭据线索的（泄露命中）· 独立 IP 段（dedupe.py 的 /24 聚类可看）· 管理后台/SSO/VPN · 刚签发证书的新站（CT 时间戳新）。

## §5 风险排序（给 src-dig 的进站顺序建议）

简化评分模型（满 100）：

| 因子 | 分值 | 判据 |
|------|------|------|
| 可达性 | 30 | 公网 200/登录墙 vs 内网/超时 |
| 技术脆弱 | 25 | 老版本组件/已知 CVE 候选/默认口令指纹 |
| 暴露面 | 20 | admin/swagger/actuator/上传/文件接口 |
| 情报命中 | 15 | 泄露库/招标系统名/JD 技术栈交叉确认 |
| 业务价值 | 10 | 支付/HR/财务/核心业务对象 |

排序输出前 N 个「建议进站顺序」附在资产表尾。**只是建议**——进站节奏仍认 `dig-scope`（力气先砸哪认 `src-value-hunting` §1.1）。

## §6 落盘规范（BLADEPRO）

独立会话写到会话工作目录，任务写到任务目录（file-guard 只允许 `data/`、`skills/`）：

```
<会话工作目录>/资产/<企业>_资产清单.md        # 对话页：<data>/sessions/<会话id>/资产/
<任务目录>/recon/资产清单.md                  # 任务：<data>/tasks/<任务id>/recon/
```

清单固定包含（Markdown 表格，禁止裸列表）：

```
1 公司树      层级 / 公司 / 持股 / 注册资本 / 法人 / 官网 / ICP / 邮箱 / 来源
2 域名资产    域名 / 所属单位 / IP / 来源 / 备注
3 IP 资产     IP / 关联域名 / 地理位置 / 运营商 / 类型（CDN/C段/真实） / 来源
4 URL·服务    URL / 系统类型 / 可访问性 / IP / 来源 / 备注
5 系统资产    系统 / 技术栈 / 单位 / 端口 / 来源（软著/招标/测绘）
6 社工线索    类型（邮箱/电话/QQ/公众号） / 内容 / 归属 / 来源
7 待授权/存疑 资产 / 类型 / 为什么不在授权内 / 建议      ← insert_assets 返回 scope_skipped 的都进这里
8 建议进站顺序（§5 评分）
9 来源与工具日志（ENScan job_id、各源条数、失败原因、未跑维度）
```

落库优先：能进 `assets` 表的（域名/IP/服务/App/接口）先 `insert_assets`，清单只是人看的汇总；两者内容必须一致。

**纪律：** 采集到一半浏览器断连前先落盘（01 §2）；JSON 字段名稳定（company/domain/ip/source/note）便于合并；每张表标日期与来源渠道。

## §7 回灌与交接

1. **优质根域回灌**：确认优质面 → 归约出搜域 R（业务簇根/品牌根，非叶子 host）→ `种子队列.md` 加 pending（备注源 host）。**本种子挖完才搜 R**（`dig-scope` §1.1.1）。
2. **交 src-dig 进站**：资产表 + 建议顺序 + 暴露面标记。进站打法/矩阵/报告全归 src-dig（触发词「挖 XX / 测这个站」）。
3. **收工自查**：过 SKILL.md「覆盖自查 10 问」再收尾；仍有 pending 种子不问句收尾（`dig-scope` §1.4）。

## §8 输出纪律汇总

- 表格输出（§1 五表），禁裸列表
- 每条带来源（可信度回溯）：测绘 A 级 / CT / 备案 / 招标 / WebSearch
- D 级测绘结果（body 搜索 IP）**禁直入资产表**（02 §2 精度分级）
- 猜测与实锤分开标注（CDN 溯源证据分级见 03 §8）
- 本技能不写漏洞报告；发现疑似漏洞面 → 备注标记交 src-dig
